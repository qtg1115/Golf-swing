# 내부 참조 점검 (cross-references)

원고는 Substack 연재 순서로 쓰였고, 책은 다른 순서로 묶였다. 그래서 2부
어세스먼트 로드맵이 아직 읽지 않은 3부 챕터를 "돌아가서 읽어라"라고 가리키고
있었다. 이 문서는 무엇을 어떻게 고쳤는지의 기록이다.

**책 순서(고정)** — 이 책을 읽는 법 · 1부 · 2부 로드맵 · 3부 스윙 시계 챕터 1–10
(릴리즈는 챕터 7 안의 절) · 4부 샷 · 부록

원인: 연재 당시 로드맵은 시계 챕터가 **이미 발행된 뒤**에 쓰였다. 책에서는
로드맵이 **먼저** 온다. 그래서 뒤를 가리키는 말이 전부 거짓이 되었다.

---

## 1. 2부 로드맵 — 방향이 뒤집혀 있던 곳

| 이전 | 이후 | 이유 |
|---|---|---|
| **돌아가서 읽을 챕터** (5회) | **3부에서 먼저 볼 챕터** | 대상이 뒤(3부)에 있음 |
| **다시 읽을 챕터** (5회) | **3부에서 볼 순서** | 대상이 뒤에 있음 |
| 다시 읽을 챕터: … (표 8행) | 3부에서 볼 챕터: … | 대상이 뒤에 있음 |
| …다시 읽어야 할 챕터를 찾아가도록 | …이어지는 3부에서 어느 챕터를 먼저 펼칠지 찾아가도록 | 대상이 뒤에 있음 |
| 가장 먼저 어드레스 챕터로 **돌아가야** 한다 | 3부에서 가장 먼저 **챕터 1 어드레스를 펼쳐야** 한다 | 대상이 뒤에 있음 |
| 테이크어웨이 챕터와 백스윙 초반 챕터를 **다시 읽는다** | 3부의 챕터 2 테이크어웨이와 챕터 3 백스윙 하프웨이를 **먼저 본다** | 대상이 뒤에 있음 |
| 백스윙 챕터로 **돌아간다** | 3부의 챕터 3 백스윙 하프웨이와 챕터 4 탑 오브 백스윙을 **본다** | 대상이 뒤에 있음 |
| 전환 동작 챕터와 다운스윙 챕터를 다시 읽는다 | 3부의 챕터 5 다운스윙 전환과 챕터 6 임팩트 직전을 본다 | 대상이 뒤에 있음 |
| 다운스윙 챕터와 임팩트 챕터를 다시 읽는다 | 3부의 챕터 6 임팩트 직전과 챕터 7 임팩트를 본다 | 대상이 뒤에 있음 |
| 임팩트 챕터와 3시 팔로우스루 챕터를 다시 읽는다 | 3부의 챕터 7 임팩트와 챕터 8 팔로우스루를 본다 | 대상이 뒤에 있음 |
| 3시 팔로우스루 챕터를 다시 읽는다 | 3부의 챕터 8 팔로우스루를 본다 | 대상이 뒤에 있음 |
| 피니시 챕터와 함께 앞 단계인 … 다시 확인한다 | 3부의 챕터 10 피니시와 함께, 그 앞 단계인 챕터 5·7·8을 확인한다 | 대상이 뒤에 있음 |
| 그러므로 **이 책을 다시 읽을 때는** 이렇게 접근하면 된다 | 그러므로 **이어지는 3부는** 이렇게 읽으면 된다 | 아직 읽지 않은 파트 |
| 그보다 한 단계 앞의 챕터로 **돌아간다** | 3부에서 그 구간의 챕터, 그리고 그보다 한 단계 앞의 챕터를 **펼친다** | 대상이 뒤에 있음 |

## 2. 이 책에 없는 챕터 이름 → 실제 위치로

로드맵은 연재 시절의 느슨한 이름으로 가리켰다. 대상은 그대로 두고 이 책의
챕터 번호로 바꿨다. 없는 목적지를 새로 만들지 않았다.

| 이전 이름 | 이후 | 이유 |
|---|---|---|
| 어드레스 챕터 | 챕터 1 어드레스 | 같은 대상, 번호 명시 |
| 테이크어웨이 챕터 | 챕터 2 테이크어웨이 | 같은 대상 |
| 백스윙 챕터 | 챕터 3 백스윙 하프웨이, 챕터 4 탑 오브 백스윙 | 책은 백스윙을 두 장으로 나눔 |
| 백스윙 초반 챕터 | 챕터 2 테이크어웨이 + 챕터 3 백스윙 하프웨이 | 같은 구간 |
| 백스윙 중심축 챕터 | 챕터 3 백스윙 하프웨이 | 그 장의 내용 |
| 백스윙 꼬임 챕터 | 챕터 4 탑 오브 백스윙 | 꼬임을 다루는 장 |
| 전환 동작 챕터 | 챕터 5 다운스윙 전환 | 같은 대상 |
| 다운스윙 (체중 이동) 챕터 | 챕터 5 다운스윙 전환 (체중 이동) | 같은 대상 |
| 다운스윙 챕터 | 챕터 5 다운스윙 전환, 챕터 6 임팩트 직전 | 두 장에 걸쳐 있음 |
| 임팩트 챕터 | 챕터 7 임팩트 | 같은 대상 |
| 3시 팔로우스루 / 팔로우스루 챕터 | 챕터 8 팔로우스루 — 3시 | 같은 대상 |
| 피니시 챕터 | 챕터 10 피니시 | 같은 대상 |
| 척추각 유지 챕터 | 챕터 1 어드레스 (척추 각도) | 독립 장이 아니라 어드레스 안의 내용 |
| 그립 / 그립과 어드레스 챕터 | 1부의 손 그립, 그리고 챕터 1 어드레스 | 독립 장이 없음. 그립은 1부와 챕터 1에 있음 |

## 3. 잘못된 장을 가리키던 곳

| 파일 | 이전 | 이후 | 이유 |
|---|---|---|---|
| p3-c8 (챕터 8) | **앞 장에서** 이야기했듯 골프공을 친 뒤 땅을 맞춘다는… | **챕터 6에서** 이야기했듯 … | 그 내용은 챕터 7이 아니라 챕터 6(벤 호건)에 있다 |
| p4-c1 (4부) | 날개뼈는 **앞선 챕터에서** 이야기 했듯 | 날개뼈는 **3부에서** 이야기했듯 | 파트를 건너 가리키므로 파트를 밝힘 |

## 4. 그림 안에 박힌 뒤 방향 (원본 이미지 수정 필요)

두 장의 로드맵 그래픽에는 뒤를 가리키는 문구가 **이미지 안에** 들어 있다.
그림을 다시 그리지 않고는 글자를 바꿀 수 없어, 방향을 바로잡는 캡션을 달았다.
**작가 확인 후 그래픽 재작업 권장.**

| 그림 | 이미지 안 문구 | 바꿔야 할 말 |
|---|---|---|
| `p2-c1-02` 스윙 어세스먼트 로드맵 | 부제 “문제 발견 → 원인 추적 → **다시 읽을 챕터**”, 3단계 제목 “**복습 챕터 연결**”, 본문 “한 단계 앞 챕터부터 **다시 읽기**” | “3부에서 볼 챕터” / “해당 챕터 연결” / “한 단계 앞 챕터부터 읽기” |
| `p2-c1-05` 빠른 진단 맵 | 열 제목 “**돌아갈 챕터**”, 사용법 “해당 챕터 **복습**” | “3부에서 볼 챕터” / “해당 챕터 확인” |

`p2-c1-03`(1단계)과 `p2-c1-04`(2단계)는 문제없다. “점검”이라는 말만 쓰고,
2단계의 8구간 순서(어드레스 → 테이크어웨이 → 백스윙 → 전환 → 다운스윙 →
임팩트 → 3시 팔로우스루 → 피니시)도 책의 순서와 같다.

## 5. 확인해서 **그대로 둔** 참조

모두 실제로 앞을 가리킨다. 고칠 것이 없다.

| 파일 | 참조 | 가리키는 곳 |
|---|---|---|
| p3-c6 (챕터 6) | 앞선 챕터에서 다룬 셋업, 힘의 저장… | 챕터 1–5 ✓ |
| p3-c7 (챕터 7) | 앞선 챕터에서 셋업, 힘의 저장, 다운스윙 전환… | 챕터 1–6 ✓ |
| p3-c9 (챕터 9) | 앞 장에서 다룬 팔로우스루 / 앞 장의 얼리 팔로우스루 | 챕터 8 ✓ |
| p1-c2 | 앞에서 말한 손과 발의 셋업 | 같은 장 안 ✓ |
| 4부 각 장 | 페이드가 드로우를, 스팅어가 하이 런치를 비교 | 같은 파트의 앞 장 ✓ |
| 부록 | “다른 장을 읽다 용어가 걸리면 여기로 돌아온다” | 사전으로 돌아오라는 뜻 ✓ |
| 3부 도입 | 앞 장의 조건이 갖춰졌다는 전제 | 3부 안의 앞 장 ✓ |

`돌아가/돌아간다`가 남아 있는 다른 자리는 모두 신체 회전이나 공의 궤적을
말하는 표현이다(골반이 돌아간다, 페어웨이로 돌아오는 샷). 내부 참조가 아니다.
