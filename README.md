# Golf-swing

Publishing repo for the Korean golf ebook **「골프 느낌의 실체」**
(프로가 말하는 감각을 실제 현상으로 풀다) by 이충원 Logan Lee · 방승호 Bryan Bang ·
박세인 Jason Park.

- Source, images, manifests and build scripts: [`ebook/`](ebook/README.md)
- Built files: `dist/golf-neukkimui-silche.epub`, `dist/golf-neukkimui-silche.pdf`

To rebuild:

```bash
cd ebook && make
```

Videos are pending YouTube unlisted upload to the 골프 느낌의 실체 channel; QR codes
are generated only once those URLs exist. See
[`ebook/README.md`](ebook/README.md) for the inventory and current status.
